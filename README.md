# CE Summaries

My summaries from every computer engineering subject I take, all in one place.

## Why this repo exists

I started writing these summaries for myself. Writing things down in my own words is the only way I actually understand what a subject is trying to teach me. After a while I had a pile of notes, and it felt like a waste to keep them on my laptop.

So I put them here. If they help you understand a topic a little faster, great.

## What's inside

Each subject has its own folder. Inside you'll find my notes on the main topics, plus labs and examples where they make sense.

| Subject | What it covers |

| Introduction to Computer Engineering | curl, VM and SSH, Docker, Linux basics |

| More coming... | I add a new folder as I finish each subject |

## A quick heads-up

I'm a 1st year student, still learning. These notes are how I understood things at the time, so a few parts may be incomplete or just plain wrong. If you spot a mistake, please tell me.

## Contributing

Found an error or have a better way to explain something? Open an issue or send a pull request. I'd be glad to learn from it.
